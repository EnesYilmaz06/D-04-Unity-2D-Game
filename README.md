# D-04 | Unity 2D Game

## Proje Hakkında
D-04, Unity oyun motoru ve C# programlama dili kullanılarak geliştirilmekte olan 2D platform oyunudur.

Oyun, "Sistem" adı verilen dijital bir evrende geçmektedir. Oyuncu, D-04 isimli kapsül karakterini kontrol ederek engelleri aşmaya çalışır.

## Kullanılan Teknolojiler
- Unity 2D
- C#
- Visual Studio Code

## Tamamlanan Özellikler
- Karakterin zıplama mekaniği
- Karakter tasarımı
- Dijital arka plan tasarımı

## Geliştirilmekte Olan Özellikler
- Engellerle çarpışma ve ölüm sistemi
- Oyunun yeniden başlatılması
- Oyun deneyiminin iyileştirilmesi

## Proje Durumu
Bu proje aktif olarak geliştirilmektedir. Yeni özellikler ve iyileştirmeler eklenecektir.
